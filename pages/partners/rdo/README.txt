Структура партнёра РДО
======================
pages/partners/rdo/
  index.html
  image/
    logo_rdo.svg      ← логотип (положите файл сюда)
    rdo-poster.jpg    ← постер для видео (опционально)

  /pages/partners/rdo/image/logo_rdo.svg

Совпадает с локальным:
  ...\pages\partners\rdo\image\logo_rdo.svg
