# Портфолио KONTURBIZ

## Структура (как база знаний)

```
pages/portfolio/
  index.html              — хаб разделов
  websites/index.html     — сайты
  brandbooks/index.html   — брендбуки
  polygraphy/index.html   — полиграфия
  packaging/index.html    — упаковка
  outdoor/index.html      — наружная реклама
  digital/index.html      — цифровые носители
```

## Отличие от кейсов

| Раздел | Назначение |
|--------|------------|
| `/pages/portfolio/` | Визуальные работы и носители |
| `/pages/cases/` | Разбор задачи → решение → результат |

## Как добавлять работу

1. Папка проекта, например: `pages/portfolio/websites/project-slug/`
2. `index.html` работы + изображения в `image/` или `/images/portfolio/...`
3. Карточка на `websites/index.html` и при необходимости на хабе

Пока карточки-заглушки: «работы готовятся к публикации» — без выдуманных проектов.
