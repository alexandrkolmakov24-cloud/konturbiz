# KONTURSCAN — установка

## Что это

Готовый модуль бесплатной бизнес-диагностики для установки в корень KONTURBIZ как `/konturscan/`.

Архитектура:

`HTML/CSS/JS → диагностический движок → AI Core → Gemini → JSON → отчёт`

Загрузка сайта пользователем не требуется.

## 1. Копирование

Скопируйте папку `konturscan` в корень сайта:

`/konturscan/`

Открытие:

`https://ВАШ-ДОМЕН/konturscan/`

## 2. Gemini API

Откройте:

`konturscan/config/config.php`

и замените:

`PASTE_GEMINI_API_KEY_HERE`

на ваш ключ Gemini API.

Ключ хранится только на сервере и не попадает в JavaScript браузера.

По умолчанию используется `gemini-3.6-flash`. Модель можно изменить в этом же файле.

## 3. Требования сервера

- PHP 8.0+ желательно 8.1+
- расширение cURL
- HTTPS
- сервер должен разрешать исходящие HTTPS-запросы к `generativelanguage.googleapis.com`

Python, Node.js и база данных для базовой версии не нужны.

## 4. Проверка

1. Откройте `/konturscan/`.
2. Пройдите вопросы.
3. После ответов должен появиться результат.
4. При настроенном API появится AI-интерпретация.
5. Кнопка «Сформировать PDF» использует системную печать браузера — выбрать «Сохранить как PDF».

## 5. Если AI не настроен

Сканер всё равно сформирует результат на основе правил и три рекомендации. В результате будет указано, что AI Core недоступен.

## 6. Важно для текущего сайта

Модуль не требует изменений существующих страниц. Его можно устанавливать отдельной папкой.

Ссылку на него можно добавить в текущий сайт как:

`/konturscan/`

## 7. Бренд

CSS использует интерфейсные токены KONTURBIZ: navy, gold UI, dark gold text, blue secondary. Временный текстовый знак KONTURBIZ в шапке заменяется на существующий официальный логотип сайта при интеграции с текущим header.

## 8. База знаний

`knowledge/` содержит компактную рабочую базу для AI Core. Расширять её можно MD-файлами без изменения frontend.

`data/products.json` — каталог решений, доступный диагностическому движку.
`data/rules.json` — правила сопоставления.
`data/questions.json` — анкета.
