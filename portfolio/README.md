# Портфолио KONTURBIZ

Корень сайта: `/portfolio/`

## Структура

```
portfolio/
  index.html                 — хаб разделов
  websites/index.html        — сайты
  graphic-design/index.html  — графический дизайн
  branding/index.html        — брендирование
  polygraphy/index.html      — полиграфия
  packaging/index.html       — упаковка
```

Старый путь `/pages/portfolio/` — редирект на `/portfolio/`.

## Отличие от кейсов

| Раздел | Назначение |
|--------|------------|
| `/portfolio/` | Визуальные работы и носители |
| `/pages/cases/` | Разбор задачи → решение → результат |

## Как добавлять работу

1. Папка проекта, например: `portfolio/websites/project-slug/`
2. `index.html` работы + изображения
3. Карточка на странице раздела и при необходимости на хабе

Пока карточки-заглушки: «готовится к публикации» — без выдуманных проектов.

## Связанные услуги

- Сайты → `/pages/services/web-development.html`
- Графический дизайн / полиграфия → `/pages/services/graphic-design.html`
- Брендирование / упаковка → `/pages/services/branding.html`
